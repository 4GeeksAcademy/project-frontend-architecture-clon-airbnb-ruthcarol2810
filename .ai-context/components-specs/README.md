# Especificaciones de componentes

Este directorio contiene los contratos de componentes para las tres vistas del clon de Airbnb:

- Componentes compartidos: navegación, búsqueda, categorías, tarjetas, estados de carga y pie de página.
- Catálogo: barra de resultados, filtros y mapa.
- Detalle de alojamiento: galería, reserva, anfitrión, amenities, calendario, reseñas y ubicación.

Todas las especificaciones siguen una estrategia mobile-first basada en las capturas de `assets-dev/reference-image/`.
